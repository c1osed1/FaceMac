# FaceMac

**Посмотри на Mac. Он откроется.**

Открытая разблокировка по лицу для macOS — бесплатно, приватно, живёт в нотче.
Без подписки. Без облака. Без аккаунта. Твоё лицо не покидает машину.

## Суть

Закрыл крышку, открыл — и снова вводишь пароль.

**FaceMac узнаёт тебя через встроенную камеру и вводит твой сохранённый пароль
на твоём экране блокировки.** Нотч подсвечивается, сканирует, рисует галочку —
и ты уже внутри. Около секунды, и камера гаснет.

## Почему переходят

- **Навсегда бесплатно.** Один бинарник, GPL-3.0, без триалов и ключей.
- **Приватно по конструкции.** Кадры не пишутся на диск. Отпечатки лица и пароль
  не покидают машину.
- **Нотч — это интерфейс.** Растёт из нотча, пульсирует зелёным глифом лица, пока
  смотрит на тебя, и сворачивается в галочку.
- **Понимает, что это не ты.** Чужой получает отказ за ~0,4 с с красной тряской.
- **Камера выключается.** 5 секунд без совпадения — стоп.
- **ML на устройстве.** SFace через CoreML, 128-мерные эмбеддинги, калибровка под лицо.

## Возможности

|                      |                                                                       |
| -------------------- | --------------------------------------------------------------------- |
| Оверлей нотча        | Настоящий `NSPanel` поверх всего, включая экран блокировки (SkyLight) |
| Анимация как Face ID | Зелёный скан → морф в галочку (Lottie)                                |
| Регистрация по шагам | Пять подсказок — прямо, влево, вправо, наклоны — с живым кольцом      |
| Отторжение           | «Явно не ты» ловится сразу и трясётся в красном                       |
| Liveness             | Проверка моргания / микродвижения отсеивает фото, на устройстве       |
| Калибровка           | Порог совпадения подстраивается под твоё лицо, камеру и свет          |
| Анти-дрейф           | Должны совпасть и лучший эталон, **и** центроид, N кадров подряд      |
| Отсев кадров         | Мелкие и сильно повёрнутые лица игнорируются, а не угадываются        |
| Кнопка повтора       | Стеклянная кнопка на локскрине, чтобы попробовать снова               |
| Языки                | English, Русский, 中文 — авто по системе или вручную                    |
| Приватность          | Всё локально, камера останавливается, когда закончила                 |

## Как это работает

```
кадр с камеры
  → детекция лица и 5 точек (Apple Vision)
  → similarity-выравнивание в кадр 112×112 (ArcFace)        (FaceAligner)
  → эмбеддинг SFace через CoreML, 128-d, L2-норма           (MLFaceEmbedder)
  → косинусная близость с регистрацией                      (FaceMatcher)
  → лучший + центроид + 3 кадра подряд должны совпасть
  → проверка моргания / микродвижения                       (LivenessTracker)
  → ввод пароля из Keychain через CGEvent                   (KeyboardInjector)
```

Ни один кадр не пишется на диск и никуда не отправляется.

## Установка

### Из релиза (проще всего)

Скачай [последний релиз](https://github.com/c1osed1/FaceMac/releases/latest),
перетащи **FaceMac** в **Applications**, при первом запуске — правый клик →
**Открыть** (сборки пока не нотаризованы).

### Через Homebrew

Пока нет в официальном `homebrew/cask` (релизы не нотаризованы), поэтому свой tap:

```sh
brew tap c1osed1/facemac https://github.com/c1osed1/FaceMac.git
brew install --cask --no-quarantine c1osed1/facemac/facemac
```

Cask лежит в [`Casks/facemac.rb`](Casks/facemac.rb).

### Из исходников

```sh
git clone https://github.com/c1osed1/FaceMac.git
cd FaceMac

scripts/fetch-model.sh   # соберёт CoreML-модель SFace (один раз, нужен Python 3.12+)
scripts/install.sh       # сборка, установка в ~/Applications и запуск
```

### Дальше из иконки в меню-баре

1. **Задать сохранённый пароль…** — пароль входа в macOS, в Keychain.
2. **Разрешить Accessibility…** — чтобы вводить пароль на локскрине.
3. **Зарегистрировать лицо…** — пять быстрых поз головы.
4. Оставь **Включено** и заблокируй Mac (`⌃⌘Q`).

**Показать анимацию нотча** в меню прогонит всё это без блокировки.

## Требования

- Mac на Apple silicon, macOS 14 или новее
- Встроенная камера (Continuity Camera не используется)

Разрешения привязаны к стабильной подписи кода, поэтому пересборка сохраняет
доступ к камере и Accessibility.

## Безопасность, честно

FaceMac — это **удобство**, а не апгрейд безопасности.

- Встроенная проверка liveness (моргание / микродвижение) отсеивает статичное
  фото, но не защищает от подмены: хорошее видео с тебя на экране телефона может
  пройти. Отключи или ослабь её в Настройках → Распознавание, если мешает.
- Он хранит пароль входа в macOS в Keychain, потому что так он его вводит. Он не
  покидает машину — но он **есть** на машине.
- Он не может запереть тебя снаружи: если он не сработал или ты его закрыл —
  логинишься как обычно.
- Распознавание не запускается, пока экран разблокирован; камера выключена, если
  скана нет.

## Сборка из исходников

```sh
swift build          # ядро + CLI
swift test           # юнит-тесты, включая паритет CoreML ↔ ONNX
xcodegen generate    # создать FaceMac.xcodeproj
```

Структура:

```
Sources/
  FaceMacCore/     камера, выравнивание Vision, SFace-эмбеддер, матчинг,
                   Keychain, слежение за блокировкой, ввод через CGEvent
  FaceMacApp/      меню-бар, оверлей нотча, окно настроек
  FaceMacDemo/     CLI без UI (info / enroll / match)
Tools/Conversion/  конвертация SFace ONNX → CoreML + golden-эмбеддинг
Tools/Icon/        генератор иконки приложения
scripts/           fetch-model.sh, install.sh, make-icon.sh
```

## Релизы

Релизы собирает GitHub Actions (`.github/workflows/ci.yml`):

- каждая сборка/PR собирает приложение и публикует DMG-артефакт;
- коммит с `[RELEASE] x.y.z` или ручной запуск workflow **Build** публикует
  GitHub Release с этим DMG.

Локально:

```sh
xcodebuild -project FaceMac.xcodeproj -scheme FaceMac -configuration Release \
  -derivedDataPath .build/ReleaseData build
scripts/make-dmg.sh .build/ReleaseData/Build/Products/Release/FaceMac.app FaceMac-0.1.1.dmg
```
